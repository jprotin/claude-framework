---
description: Démarre l'interface web MkDocs Material pour naviguer les artéfacts des features du projet courant (spec, plan, tasks, validation, docs). Hot-reload automatique.
---
Lance l'interface web de navigation des features.

Exécute la commande suivante dans le terminal :

```bash
bash ~/.claude/bin/feature-serve.sh
```

L'interface sera disponible sur http://localhost:8888

Si un port différent est souhaité, passer en argument : `feature-serve 9000`
